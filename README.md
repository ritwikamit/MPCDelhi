# My Photo Club (MPC Delhi)

Professional Wedding Photography & Filmmaking Studio by Nagender Kumar, based in Delhi NCR.

## Features
- **Cinematic Photography & Film Showcases**: High-resolution gallery and dedicated categories for Wedding, Pre-Wedding, Maternity, Baby Shoots, and Commercial events.
- **Interactive Lightbox & Modals**: Immersive image viewer with touch-friendly navigation and full metadata.
- **Direct WhatsApp & Online Booking Inquiries**: Seamless inquiry and booking system.
- **Tailwind CSS & Vite**: Ultra-fast performance and sleek, modern typography.

## Tech Stack
- **Framework**: React 19 + TypeScript
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Bundler**: Vite 6

## Development
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Deployment
Automated continuous deployment via Vercel on push to the `main` branch.
